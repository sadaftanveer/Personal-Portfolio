 Personal Portfolio

A responsive personal portfolio website 

The portfolio showcases my education, technical skills, university project, practical experience, and contact information.

Features

- Responsive design for desktop, tablet, and mobile
- Fixed navigation bar
- Responsive mobile navigation
- Smooth section navigation
- Hero section with social links
- About Me section
- Technical Skills section
- Education section
- Project showcase
- Experience section
- Contact section
- Footer with social links
- Reusable React components
- Hover effects and subtle animations

 Technologies Used

- React
- TypeScript
- Vite
- CSS3
- React Icons
- Google Fonts (Poppins)



Installation:

Clone the repository:
git clone https://github.com/sadaftanveer/Personal-Portfolio.git



Navigate to the project folder:



Install dependencies:
npm install



Run Locally:

Start the development server:
npm run dev

Open the URL displayed in the terminal, usually:
http://localhost:5173



Production Build
Create a production build:
npm run build

Preview the production build:
npm run preview
